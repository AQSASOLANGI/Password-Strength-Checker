# 🔐 Password Strength Checker

A simple **Password Strength Checker** built with **Python** and **Streamlit**.  
It evaluates passwords based on common security rules and provides suggestions to improve weak passwords.

---

## Features

- Checks password length (minimum 8 characters)
- Detects presence of:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters (`@ # $ % ! & *`)
- Provides a **strength score** and **visual meter**
- Suggests improvements for weak passwords
- Fun animations for strong passwords 🎉
